# Yahoo Fantasy Football Manager

A personal AI-assisted fantasy football management project built for my own Yahoo Fantasy Football league.

## Purpose

This application uses the Yahoo Fantasy Sports API to retrieve read-only fantasy football data for analysis and decision support.

The application is intended to help with:

* Starting lineup recommendations
* Waiver wire analysis
* FAAB recommendations
* Add/drop recommendations
* Trade evaluation
* Injury and player-status analysis
* Bye-week planning
* Matchup analysis
* Season-long roster management

## Yahoo Fantasy Sports API

The application will use authorized read-only access to retrieve information such as:

* League settings
* Team roster
* Matchups
* Standings
* Available players
* Player information and statistics
* Transactions and waiver information

Any roster changes or transactions recommended by the application will be manually executed by the team owner through Yahoo Fantasy Sports.

## Usage

This is a private-use project intended for a single user and their personal Yahoo Fantasy Football league. Yahoo Fantasy Sports data will not be sold, redistributed, or publicly published.
